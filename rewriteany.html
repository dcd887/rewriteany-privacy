✍️ RewriteAny

AI Text Rewriter, right in your browser

Select any text on any page, right-click, and rewrite it with AI — using your own API key. Your text stays private.

How it works

  • 🖱️ Select any text on any webpage, then right-click
  • 🤖 Choose a rewrite action (formal, concise, friendly, etc.)
  • 🔑 Bring Your Own Key — connect OpenAI, Anthropic, or Google Gemini
  • 🔒 Private by design — text goes directly from your browser to the AI provider. No RewriteAny servers involved.

Key features

  • Right-click context menu integration
  • Multiple rewriting tones and styles
  • Supports OpenAI, Anthropic, and Google Gemini
  • Token usage tracking to monitor API costs
  • Your API key stays local, never uploaded

Privacy

RewriteAny uses a Bring-Your-Own-Key model. Your selected text is sent only to the AI provider you choose, using your own API key. Your API key is stored locally with obfuscation, and no data is ever transmitted to RewriteAny servers.
